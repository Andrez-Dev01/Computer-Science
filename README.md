# Computer Science Knowledge (Obsidian vault)

A **public-ready, study-first** Markdown vault template. Subjects hold college courses, independent learning, and optional quick reference notes. No separate duplicated global concept library.

## Start
1. Open the folder `CS-Knowledge-Vault` as a vault in Obsidian (not its parent folder).
2. Open **START HERE.md**.
3. Follow `00 - Guides/01 - Setup in Obsidian.md`.

**Project documentation is deliberately excluded.** It has its own independent vault (`Software-Projects-Vault`). This repository is not initialized automatically; review all content before making it public.

## Privacy and copyright
Only add original summaries, self-written programs, and appropriately attributed links and references. Do not add scans, paid textbook pages, access keys, or personally identifying coursework. Read `00 - Guides/05 - Publishing a Public GitHub Vault Safely.md` before any push.
