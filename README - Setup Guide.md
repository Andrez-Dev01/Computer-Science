# Obsidian CS Major Workspace

A balanced starter vault for a sophomore Computer Science student focusing on Programming, Data Structures, and Math.

## Getting started
1. Unzip this folder.
2. In Obsidian, choose **Open folder as vault** and select the `Obsidian_CS_Major` folder, or copy its contents into an existing vault.
3. Go to **Settings → Core plugins** and enable **Templates**.
4. Go to **Settings → Templates** and set **Template folder location** to `Templates`.
5. Open `CS Dashboard.md` to use your home page.
6. Fill in the three course notes under `Courses/`.

## Templates included
- `Course Template.md`
- `Lecture Template.md`
- `Assignment Template.md`
- `Study Session Template.md`
- `Project Template.md`

To use a template, create a note, open the Command Palette (`Ctrl+P` on Windows/Linux), choose **Templates: Insert template**, and select the template.

## Placeholder note
Obsidian's built-in Templates plugin supports `{{title}}` and `{{date}}`. It does not automatically fill custom YAML properties or create a dynamic deadline dashboard. Replace placeholders and maintain the dashboard manually.

## Suggested workflow
- After class: create a lecture note.
- For each assignment: create an assignment note and record its due date.
- During study sessions: use the study session template and track mistakes.
- Weekly: update the dashboard and review weak topics.

## Notes
The course topics are examples, not a required curriculum. Adapt them to your actual syllabus.
