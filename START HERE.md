## My rules
- One note per **actual textbook section**; inside it, one repeatable note block per topic.
- College notes, lectures, assignments, and personal explanations are together **inside that section note**.
- Independent lessons follow the resource when structured; ad hoc research is topic-based.
- Full runnable code is written in a real editor. Notes store compact samples, explanations, and a **safe repo link or path label**, not private source.
- Review manually: reread key facts, explain without looking, write a small program.
- Sources go next to the claims/code they support. Mark what I personally tested.
- No forced concept notes, no forced backlinks, no mandatory weekly review.

> [!warning] Public repository
> Everything in tracked `.md` files is visible when published. Do not paste paid textbook pages, private source code, private URLs/tokens, personal information, or restricted assignments. `.gitignore` is not a copyright or security filter for text already written into Markdown.
