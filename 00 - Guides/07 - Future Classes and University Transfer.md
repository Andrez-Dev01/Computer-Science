# Adding New College Classes Later

You don't need to know your future university course list now.

1. Pick the most relevant **existing CS subject** (e.g. DSA, Operating Systems, or Software Engineering).
2. Under `01 - College Courses`, create a folder named `School - Course Name`.
3. Add `00 - Course Home.md` by inserting **03 - Course Home**.
4. For each textbook chapter, create `Chapter 01`, `Chapter 02`, and a `00 - Chapter 01 Map.md` from **04 - Chapter Map**.
5. Add **one note per actual textbook section** (not per topic). Insert **01 - College Section** and as many **02 - Repeatable Topic Blocks** as the section needs.
6. When a topic appears in another class, keep that class's note self-contained. Only make optional links or concise shared references if useful.

If a course spans two major subjects, choose one main subject home and link to it from the other. Don't copy all the notes into both.
