# Public GitHub Checklist

This vault is intended to be public. **Review the entire change before every push.**

- [ ] I wrote the notes in my own words, without reproducing substantial passages from paid textbooks.
- [ ] I did not include paid textbook scans, restricted slides/handouts, solutions, or materials I cannot share.
- [ ] I did not include passwords, API keys, tokens, private URLs, contact information, or private research.
- [ ] I checked code blocks and pasted content inside `.md` notes, not only attached files.
- [ ] I checked that only files I intend to make public are staged (`git status`, `git diff --cached`).
- [ ] I checked linked images/attachments and their right to redistribute.

## What .gitignore can and cannot do

`.gitignore` prevents **matching, untracked** files from being added by default. It **does not** exclude files already tracked, redact content in `.md` files, remove content from Git history, or legally authorize redistribution. Keep private materials completely outside the public repository when possible.
