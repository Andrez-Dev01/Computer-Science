## 🧑‍🏫 Notes from Section
- AddTwo.asm program
	- On line one we are entering the program called main procedure
	- Line two we are placing the integer 5 to the EAX register
	- Line 3 we add 6 to the EAX register giving a new value of 11
	- Line 5 is a WIndows service function named ExitProcess
		- This pauses the program and returns control to the OS
	- Line 6 ends the program procedure

## 💻 Code / Worked Example
AddTwo.asm
```Assembly
main PROC
	mov eax, 5 ; move 5 to the eax register
	add eax, 6 ; add 6 to the eax register
	
	INVOKE ExitProcess, 0 ; ends the program
main ENDP
```
