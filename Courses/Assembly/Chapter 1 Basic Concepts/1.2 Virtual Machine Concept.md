## 🔑 Key Concepts
### Virtual Machine Concept
- **Definition:** A way of showing how each layer in a computer architecture presents an abstraction of a machine
- **Why it matters:** It's to help understand how computers execute programs with instructions at different levels 
- **Example:** L0 is level 0 where its written in machine code language and when introducing new language at L1
### Virtual Machines
- **Definition:** Instead of only using languages we can use terms of a hypothetical computer (virtual machine) at each level
	- which is a software program that emulates functions of other physical or virtual computer
### The Specific Machine Layers
- **Level 1** - **==🔴Digital Logic Hardware==** : the physical foundation made of transistors, logic gates, and electrical circuits
- **Level 2** - **==🔴Instruction Set Architecture (ISA)==** : this is called the **machine level** and this is where native binary instructions that the processor executes directly or via an embedded internal program called **microcode interpreter** or **microprogram**
- **Level 3 - ==🔴Assembly Language==:** Uses textual mnemonics that translate 1 to 1 into level 2 code via an assembler
- **Level 4 - ==🔴High Level Languages==:** these are languages like C++ Python Java that use powerful statements translated by compilers through assembly into machine code
