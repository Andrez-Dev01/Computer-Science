## 🔑 Key Concepts
### Assembler
- **Definition:** its a utility program that converts code programs from assembly language into machine language
- **Why it matters:** Its how we talk to the computer
- **Example:** Think of a compiler like for C++ it turns code we write into readable machine code
### Linker
- **Definition:** tool to combine individual files created by an assembler into a single executable program
- **Example:** Think of how when we create a C++ project we create a executable file to connect the entire program to run
### Machine Language
- **Definition** : a numeric language specifically understood by a CPU
- **Why it matters:** its the common language all x86 processors understand 
### High Level Languages
- **Definiton:** languages like C++ and Python 
	- They are also a many to one combination to assembly where assembly can read from many languages
## 🧑‍🏫 Notes from Section
- You need to be running 32 or 64 bit version of Windows and recent version of Visual Studio
- You can create either 32 bit protected mode programs that can run on both versions and are easier to build or 64 bit programs but can only run on 64 bit Windows
- Assembly is written of consistent states written with short mnemonics like ADD, MOV, SUB and CALL
	- It also has a one to one connection to machine code
### Registers 
- **Definition:** are named storage locations in the CPU that hold intermediate results of operations
- **Why does it matter?:** It matters because we are going to be working with all the registers in a x86 processor which there are 16 of them covered in later chapters
- **Examples:** Look at the coded example how we used two different registers comparing to C++ writing

## 💻 Code / Worked Example
- Here is an example of writing C++ compared to Assembly 
	- We see that for just simple math it requires multiple statements to write in Assembly compared to C++
```C++
// Add a code example or pseudocode
int Y;
int X = (Y + 4) * 3;
```
```Assembly
mov eax, Y ; move Y to the EAX register
add eax, 4 ; add 4 to the EAX register
mov ebx, 3 ; move 3 to the EBX register
imul ebx   ; multiply EAX by EBX
mov X, eax ; move EAX to X
```
