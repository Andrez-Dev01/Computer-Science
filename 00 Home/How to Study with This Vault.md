# How to Study with This Vault

## 1. Read the chapter note in order
Your Chapter 1 note follows Chapter 1. Your Chapter 2 note follows Chapter 2, and so on.

## 2. When you see a concept link
Example:

`[[Binary Numbers#^what-is-it|Binary Numbers]]`

Hover it to see the quick definition.

## 3. Click when you need more
The concept page contains:
- chapter connections
- C++ / Python / Go examples
- Java/JVM when relevant
- PostgreSQL / SQL connections when relevant
- space for your own example

## 4. Keep one concept page
If a later chapter discusses `Registers`, update the same `Registers.md`.

## 5. Add your own understanding
The generated material is the structure. Your job is to add:
- class examples
- questions
- diagrams
- code you wrote
- mistakes you made
- things you finally understood
