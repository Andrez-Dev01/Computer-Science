# Assembly Language

## What is it?

> [!abstract] Quick meaning
> A low-level programming language that uses readable instruction names to work close to the processor and hardware.
^what-is-it

## Cross-Language Examples


### MASM
```asm
mov eax, 5

```

```cpp

x += 6;
```

### Python
```python
x = 5
x += 6
```

### Go
```go
x := 5
x += 6
```

### Java
