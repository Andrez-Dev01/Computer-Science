## Cross-Language Examples


### C++
```cpp
int x = 0b1010;   // 10
```

### Python
```python
x = 0b1010
```

### Go
```go
x := 0b1010
```

### Java
```java
int x = 0b1010;
```

### PostgreSQL
```sql
SELECT B'1010'::bit(4);
```
