# SQL Data Types

## What is it?

> [!abstract] Quick meaning
> Database types describe the kind of value a column can store, such as INTEGER, TEXT, BOOLEAN, or BINARY-like values.
^what-is-it

## Why it matters

The database chooses logical types while the DB engine handles the lower-level machine representation.
