# Database Index vs CPU Indexed Addressing

## What is it?

> [!abstract] Quick meaning
> A database index is a data structure that speeds row lookup; CPU indexed addressing calculates memory addresses using registers and offsets.
^what-is-it

## Why it matters

They share the word 'index' but are different concepts and should not be confused.
