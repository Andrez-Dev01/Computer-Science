# SQL Recursive CTEs

## What is it?

> [!abstract] Quick meaning
> A recursive CTE repeatedly evaluates a query using previous results until no new rows are produced.
^what-is-it

## Why it matters

It solves recursive problems in a set-oriented database style rather than by directly exposing the CPU call stack.
