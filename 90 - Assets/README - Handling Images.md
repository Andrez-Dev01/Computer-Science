# Handling Attachments

- Put **original or permission-cleared public diagrams** in `00 - PUBLIC - ORIGINAL DIAGRAMS/`.
- Keep **private screenshots, scans, proprietary material, and local-only assets** in `99 - PRIVATE - LOCAL ONLY/`. This folder is excluded by `.gitignore`; it will **not** sync through Git.
- Don't add paid textbook pages or instructor materials to your public notes as images or as copied Markdown text.
- Preview staged changes before every public push. If unsure, link to the source rather than copying it.
