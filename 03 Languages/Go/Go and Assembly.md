# Go and Assembly

## Main Bridges
- function → [[Procedures]]
- arguments → [[Procedure Parameters]]
- pointers → [[Pointers]]
- function call state → [[Stack Frame]] as a machine-level concept
- recursion → [[Recursion]]
- integer types → [[Signed Integers]] / [[Unsigned Integers]]
- bitwise operators → [[AND]], [[OR]], [[XOR]], [[NOT]]
- shifts → [[Bit Shifting]]
- `if` / `for` → [[Conditional Processing]] / [[Conditional Jumps]]

The Go compiler and runtime choose the exact machine-level implementation.
