# Java and JVM Connections

Chapter 8 introduces the JVM as a comparison with x86.

## x86
x86 is primarily a register-based execution model.

- [[Registers]]
- [[Machine Language]]
- [[x86 Architecture]]

## JVM
The JVM executes [[Java Bytecode]] using a stack-oriented model.

- [[JVM]]
- [[Java Bytecode]]
- [[Virtual Machine]]

## Why compare them?
Both execute instructions, but the execution model is different:
- x86 works heavily with registers.
- JVM bytecode works heavily with an operand stack.
