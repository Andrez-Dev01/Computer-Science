# Python and Assembly

Python normally runs through a Python runtime, so do not assume one Python statement equals one x86 instruction.

## Main Bridges
- function → conceptually [[Procedures]]
- recursion → [[Recursion]]
- `if` → [[Conditional Processing]]
- Boolean logic → [[Boolean Logic]]
- bitwise operations → [[AND]], [[OR]], [[XOR]], [[NOT]]
- shifts → [[Bit Shifting]]
- lists → compare carefully with [[Arrays]]
- Python integers → compare carefully with [[Signed Integers]] because Python integers are not fixed to one CPU word
