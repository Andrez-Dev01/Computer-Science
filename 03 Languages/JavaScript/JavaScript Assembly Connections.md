# JavaScript Assembly Connections

JavaScript runs through an engine and JIT/compiler layers, so JavaScript source is much more abstract than x86 Assembly.

## Useful Bridges
- functions → [[Procedures]]
- recursion → [[Recursion]]
- Boolean logic → [[Boolean Logic]]
- conditions → [[Conditional Processing]]
- bitwise operators → [[AND]], [[OR]], [[XOR]], [[NOT]]
- shifts → [[Bit Shifting]]

## Reminder
Do not assume one JavaScript statement equals one x86 instruction.
